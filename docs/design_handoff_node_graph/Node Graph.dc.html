Two zoom levels: far shows each block as a chip (shape + title) so 25+ blocks fit on screen; near shows ports on top and fields below, each field with its own pin, and wired fields turn into ports. Pin shape carries data type. In Use layout the links themselves show how far the run got. The sample graph is the current manual-edit pipeline plus a second texture branch (11 blocks). Every window has a working Build / Use switch; click a block to select it, double-click to flip just that block between chip and fields.
